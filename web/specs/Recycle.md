# 回收站页面规格

日期：2026-10-09

- 沿用 Vue 3 Composition API、TypeScript、Element Plus 和现有布局。
- `Recycle.vue` 负责表格及头部操作；`useRecycle` 负责数据、选择、分页和分批恢复；`RecycleRestoreResults` 负责结果弹窗。
- 列表通过 GET /api/recycle 查询，恢复通过 POST /api/recycle/restore 提交 ID。
- 首列复选框支持当前页全选，无跨页保留；无选择时禁用恢复。
- 页容量仅 50/200/500/1000，默认 50。切容量归第一页，恢复后修正越界页码。
- 恢复按每批最多 50 条顺序调用，显示进度；操作中禁用表格选择及分页、刷新。
- 点击直接恢复。后端识别相同内容为已恢复，不覆盖冲突目标；页面汇总成功、已恢复、冲突、失败及逐项原因。
- 异常请求停止后续批次，提示核对实际状态，刷新列表，保留已返回结果。
- 后端成功恢复的记录退出待恢复列表，暂存备份按原期限清理。
- 验收：类型检查与构建通过，勾选、恢复结果、页码回退、1000 条分页正常。
