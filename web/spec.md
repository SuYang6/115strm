# 115strm 前端规格

本项目沿用 web/ 目录，使用 Vue 3、TypeScript、Element Plus 与现有路由和状态管理。界面包括登录、总览、115浏览、STRM生成、定时任务、回收站、设置及日志。

本次变更只统一品牌名称为115strm，更新网页标题、登录与导航品牌、设置提示、包名和登录缓存键。页面业务操作及现有布局保持一致。旧登录缓存允许一次迁移，以保留现有用户会话。

验收：前端类型检查及生产构建通过，页面品牌为115strm；Go模块、构建和部署引用同步一致。

## 2026-10-09 回收站恢复

回收站支持当前页勾选、全选和头部“恢复”操作。分页容量为 50/200/500/1000，默认 50；切页、切换容量及刷新清空选择。恢复到记录原路径，不覆盖不同内容文件，显示逐项结果及分批进度。详细规格见 `specs/Recycle.md`。
